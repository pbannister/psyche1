# prompts

This directory contains specification prompts that guide the development of the project.

## Layout

* `common/` — requirements common to the whole project.
  * `00-project.md` — project overview and high‑level goals.
  * `conventions.md` — coding conventions and style guidelines.
  * `workflow.md` — development workflow and processes.

* `features/` — requirements for each individual feature.
  * `01-facial-recognition.md` — facial recognition feature specification.
  * `02-voice-recognition.md` — voice recognition feature specification.
  * `03-speech-to-text.md` — speech‑to‑text feature specification.
  * `04-text-to-speech.md` — text‑to‑speech feature specification.
